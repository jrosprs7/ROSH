# Pricing project instructions

For creating, editing, reviewing, or migrating regional survey-pricing workbooks, read and follow [SKILL.md](SKILL.md). It defines shared formatting, setup, features, regional separation, and the requirement to notify the user about formatting issues.

Maintain one active Excel file per region and preserve current user-edited settings. Use the latest user-confirmed pricing rules. Do not start Zamboanga calculations until its source has been supplied.
